# find-skills

An agent skill for discovering and installing skills through [Skilly](https://skilly.sh/), its [public search API](https://skilly.sh/docs/search), and [`skillycli`](https://github.com/shopast/skillycli).

This repository is derived from [`vercel-labs/skills`](https://github.com/vercel-labs/skills). It retains the upstream Git history while containing only the `find-skills` skill and its license. The instructions use the Skilly catalog and CLI.

## Install

```bash
npx skillycli add shopast/find-skills --skill find-skills -g -y
```

The skill source is [skills/find-skills/SKILL.md](skills/find-skills/SKILL.md).
